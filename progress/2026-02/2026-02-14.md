# Progress: 2026-02-14

## SkillBank End-to-End Integration

Wired SkillBank infrastructure (122 tests, 10 files built in isolation) into the two systems that `--debug --debug-replay` exercises: `seed_specialist_routing.py` and `ClaudeDebugger`. Five integration gaps closed.

### Gap 1: Skill Population Script
- **New file**: `scripts/skillbank/seed_skills.py` (~150 LOC)
- CLI for bootstrapping SkillBank from episodic memory or progress logs
- Supports `--teacher claude|codex|mock`, `--from-progress-logs`, `--with-failure-context`
- Converts MemoryEntry/Trajectory → trajectory dicts → DistillationPipeline
- LocalLlamaTeacher excluded — distillation is API-only (Claude Opus 4.6 + Codex gpt-5.3)

### Gap 2: Debugger Integration
- **anomaly.py**: +2 signals (`skill_mismatch` weight=0.5, `no_skills_available` weight=0.3), +2 detector functions, extended `compute_anomaly_signals()` with 3 optional params
- **diagnostic.py**: +3 params (`skills_retrieved`, `skill_types`, `skill_context_tokens`), `skill_retrieval` block in output dict
- **claude_debugger.py**: `_get_replay_summary()` tries `SkillAwareReplayEngine` first, adds skill health via `EvolutionMonitor.get_evolution_summary()`, `_build_prompt()` displays skill retrieval data per diagnostic

### Gap 2d: API Response + Data Flow
- **responses.py**: +2 fields on `ChatResponse` (`skills_retrieved`, `skill_ids`)
- **chat_utils.py**: +`skill_ids` on `RoutingResult`
- **routing.py**: Populates `skill_ids` from `hybrid_router._last_skill_ids`
- **seeding_types.py**: +2 fields on `RoleResult` (`skills_retrieved`, `skill_ids`)
- **seeding_eval.py**: Extracts skill fields in `_build_role_result()`
- **8 ChatResponse construction sites**: All propagate `skills_retrieved` + `skill_ids` from routing
  - `repl_executor.py` (2), `direct_stage.py`, `stages.py`, `delegation_stage.py`, `vision_stage.py`, `proactive_stage.py`, `chat.py`

### Gap 3: Replay Integration
- **seed_specialist_routing.py**: `--debug-replay` section tries `SkillAwareReplayEngine` with `SkillBankConfig` before falling back to standard `ReplayEngine`. Prints skill metrics (total retrieved, coverage, avg/step)

### Gap 4: OutcomeTracker Wiring
- Initialized via `ORCHESTRATOR_SKILLBANK=1` env var
- Records `skill_id × task_id × success` after reward injection for each role result

### Gap 5: Evolution Trigger
- `--evolve` flag on `seed_specialist_routing.py`
- After replay evaluation, runs `EvolutionMonitor.run_evolution_cycle(outcome_tracker=...)` if skills.db exists
- Prints evolution report (evaluated, promoted, decayed, deprecated, redistillation candidates)
