# Progress: 2026-02-15

## Phase 2A: SoftMatcha v2 Corpus-Augmented Prompt Stuffing

Implemented the full Phase 2A pipeline from `handoffs/active/hybrid-lookup-spec-decode.md`. This injects corpus-retrieved code snippets into LLM prompts so llama-server's `--lookup` has richer n-gram material for draft token proposals.

### New Files

- `scripts/corpus/build_index.py`: Collects .py files from src/, CPython stdlib, numpy, torch. Builds word-level 4-gram index. 73,186 snippets, 5.5M n-grams, builds in 14s. Index at `/mnt/raid0/llm/cache/corpus/mvp_index/` (338MB).
- `src/services/corpus_retrieval.py`: `CorpusRetriever` singleton service with `CorpusConfig`, `CodeSnippet`, `extract_code_query()`. Lazy-loads index, sub-ms query, graceful degradation if index missing.
- `tests/unit/test_corpus_retrieval.py`: 20 tests across 8 classes — singleton lifecycle, retrieval, dedup, format budget, graceful degradation.

### Modified Files

- `src/prompt_builders/types.py`: Added `reference_code` field to `RootLMPrompt`, rendered as `## Reference Code` section before `## Task`.
